# Тайный Санта

Сайт с правилами и анкетой, случайная жеребьёвка и рассылка писем с номерами.
Получатель остаётся анонимным: участник видит только его номер и анкету.

- `index.html`, `style.css`, `script.js` — страница регистрации.
- `api/register.js` — приём анкет. `api/admin.js` — жеребьёвка, рассылка, тест почты.
- `admin.html` — страница организатора (`/admin.html`, защищена `ADMIN_TOKEN`).

## Запуск на Vercel

1. Импортируй репозиторий в Vercel (Add New → Project).
2. Storage → Marketplace → **Upstash Redis** → подключи к проекту (переменные добавятся сами).
3. В Settings → Environment Variables добавь значения из `.env.example`:
   `ADMIN_TOKEN`, `SMTP_*`, `MAIL_FROM` и по желанию `BUDGET`, `GIFT_DEADLINE`, `PARTY_DATE`, `REGISTRATION_DEADLINE`.
4. Redeploy.

## Почта

Создай отдельный ящик, например Gmail: включи двухэтапную проверку и создай «пароль приложения»
(Аккаунт Google → Безопасность → Пароли приложений). Его и вставь в `SMTP_PASS`.
Для Яндекса: `smtp.yandex.ru`, порт 465, тоже пароль приложения.

## Как провести игру

1. Раздай ссылку на сайт. Люди регистрируются.
2. Открой `/admin.html`, войди по паролю, нажми «Тест письма» и убедись, что почта работает.
3. Когда регистрация закончилась, нажми «Провести жеребьёвку» (потребуется второе нажатие).
   Каждому уйдёт письмо с его номером, номером получателя и анкетой без имени.
4. Если какие-то письма не ушли, нажми «Дослать неотправленные».

После жеребьёвки регистрация закрывается. Распределение полностью случайное: никто не дарит самому себе и нет обмена парами
(если A дарит B, то B дарит кому-то другому).

В админке есть таблица с номерами, именами, получателями и дарителями, её можно скачать в CSV. Видит её только тот, кто знает
`ADMIN_TOKEN`. Для остальных участников получатель остаётся анонимным: общего раскрытия на празднике нет, но организатор при желании
может по таблице подсказать конкретному человеку, кто его даритель или получатель.

## Локально

`npm install && npm test` проверяет жеребьёвку (нет самоподарков и взаимных пар, номера уникальны).
Сайт целиком запускается через `npx vercel dev`.
